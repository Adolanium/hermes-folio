# Notice for the live demo

The files in this folder run the three Folio plugins in a browser so the site can show them working.

- `demo.js` bundles the plugins' own page code together with interface components, icons and helpers from [Hermes Agent](https://github.com/NousResearch/hermes-agent), plus React, Radix UI and Tabler Icons. `app.css` and `demo.css` are Hermes Desktop's compiled stylesheet with its font files removed.
- Hermes Agent is Copyright (c) 2025 Nous Research and is used under the MIT License, reproduced below. React, Radix UI and Tabler Icons are also MIT licensed by their own authors.
- `playfair-800.woff2` is Playfair Display, Copyright 2017 The Playfair Display Project Authors, under the SIL Open Font License 1.1. It stands in for the app's own display font, which is not included here.
- Nothing in the demo talks to a Hermes install or to a model. Hermes' replies are scripted, and nothing a visitor does is saved or sent anywhere.
